# **App Name**: GM Biblio RDCongo

## Core Features:

- Catalogue Exploration: Browse 'Livres populaires', 'Nouveautés', and various categories (e.g., 'Business', 'Informatique') on the home screen. Display books as interactive cards with cover, title, price, and an 'Acheter' button.
- Book Search & Filtering: Utilize a prominent search bar to find books efficiently by title, author, or category.
- Detailed Book Information: View comprehensive book details including a large cover image, title, author, detailed summary, relevant tags, and price, with options for 'Acheter et Télécharger' or 'Aperçu'.
- Secure Purchase & Download: Provide a streamlined and secure payment interface for book purchases, with instant access to download purchased PDF e-books after 'Payer maintenant'.
- AI-Powered Similar Books Tool: A generative AI tool that suggests 'Livres similaires' on each book's detail page, intelligently recommending other titles based on user engagement, genre, and content attributes.
- Personal Digital Library ('Mes Livres'): Access and manage all previously purchased and downloaded digital books through a dedicated 'Mes Livres' section in the navigation.
- User Profile & Settings (including Dark Mode): Manage user account details and application preferences, including a prominent toggle for activating or deactivating a 'Mode sombre'.

## Style Guidelines:

- Primary color: Deep blue ('#0B3D91') to convey professionalism, trustworthiness, and digital sophistication, anchoring the brand identity.
- Accent color: Golden ('#F5C542') for call-to-action elements, interactive components, and highlights, adding a premium and high-quality touch.
- Background color: Pure white ('#FFFFFF') as the primary background, ensuring a clean, spacious, and minimalist aesthetic consistent with a premium user experience.
- Secondary background tint: A very subtle light blue ('#F3F6FA') derived from the primary hue, used for elevated sections or borders to add visual depth without compromising cleanliness.
- Headline Font: 'Poppins' (geometric sans-serif) for titles and headings, reflecting a precise, contemporary, and avant-garde aesthetic.
- Body Font: 'Inter' (grotesque-style sans-serif) for all body text and descriptive content, ensuring high readability, neutrality, and a professional feel across the application.
- App Logo: A modern and professional icon for 'GM Biblio RDCongo' combining an open book motif with stylized 'GM' initials, inspired by the sleek designs of leading fintech applications.
- UI Icons: Utilize a consistent set of clean, minimalist line icons for navigation, actions, and functional elements, maintaining the overall elegant design.
- Overall Layout: An ultra-clean, minimalist, and elegantly spacious interface. Content elements will feature rounded cards with subtle, light shadows.
- Navigation: Implement a fluid user interface with intuitive navigation, featuring a persistent bottom navigation bar containing 'Accueil', 'Catégories', 'Mes Livres', and 'Profil' tabs.
- Header: A prominent logo for 'GM Biblio RDCongo' positioned at the top of the screen.
- Subtle Transitions: Incorporate smooth, fluid animations such as fades and slides for page transitions, content loading, and state changes.
- Interactive Feedback: Gentle hover effects for interactive elements to provide clear visual feedback and enhance user engagement.
